# System-zarzadzanie-wydatkami
##Opis projektu
Celem projektu jest stworzenie projektu aplikacji do zarządzania własnymi finansami. Użytkownik będzie mógł dodawać swoje dochody i wydatki oraz wybierać ich kategorie, np. jedzenie, transport, zakupy czy rozrywka. Aplikacje będzie umożliwiała przeglądanie zapisanych wydatków i sprawdzanie, na co użytkownik wydaje najwięcej pieniędzy. Dane będą przedstawiony również za pomocą prostych wykresów. Aplikacja ma pomóc w lepszym kontrolowaniu i planowaniu własnego budżetu.
